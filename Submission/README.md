# Submission

This folder reorganizes the project materials from `stretch_applab`, `arduino`, and the existing dashboard assets into four review-friendly buckets.

- `uno_q/`: UNO Q firmware and App Lab sketch placeholder.
- `nano/`: Nano wearable firmware and Nano BLE forwarding helpers.
- `dashboard/`: App Lab Python dashboard package, Arduino browser dashboard tool, and standalone dashboard assets.
- `other/`: Shared technical reports, architecture notes, serial protocol docs, and project readmes.

Generated cache files such as `__pycache__` and `.pyc` files are intentionally omitted.
