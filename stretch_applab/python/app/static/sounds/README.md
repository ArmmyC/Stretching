# YUEDMAI sound effects

Put your audio files in this folder with these filenames:

| File | Used for |
| --- | --- |
| `button.mp3` | Button clicks, links, and hardware button actions |
| `countdown.mp3` | Each countdown tick before a stretch starts |
| `stretch.mp3` | Looping background music while holding a stretch |
| `complete.mp3` | Stretch/session completion chime |

MP3 is the easiest format to use in browsers. WAV and OGG can also work, but if you use them, update the paths in `../sounds.js`.

Good places to find free sounds:

- Pixabay countdown effects: https://pixabay.com/sound-effects/search/countdown/
- Mixkit free sound effects: https://mixkit.co/free-sound-effects/
- Mixkit alerts and beeps: https://mixkit.co/free-sound-effects/alerts/
- Freesound CC0 sounds: https://freesound.org/search/?q=button+click&f=license:%22Creative+Commons+0%22

Check each downloaded file's license before using it publicly.
