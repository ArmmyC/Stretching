Drop pose guideline images or videos in this folder.

Use the stretch name as a lowercase dash-separated filename:

- `wall-slides.mp4`
- `hamstring-reach.mp4`
- `overhead-reach-hold.jpg`
- `standing-side-bend-stretch.png`
- `doorway-chest-opener.webp`
- `shoulder-external-rotation.mp4`

The session guide screen appears before the first pose and during every rest.
It tries these extensions in order:

1. `.mp4`
2. `.webm`
3. `.jpg`
4. `.jpeg`
5. `.png`
6. `.webp`

Videos are shown muted, looped, and inline.
